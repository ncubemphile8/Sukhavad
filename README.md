# Sukhavad / Sukulture Fest

A dual-world brand experience for Sukhavad Couture and Sukulture Fest.

## Experience
- A split entry portal with distinct clothing and festival destinations.
- Editorial streetwear collection with interactive product detail modals, size selection, and a product enquiry bag.
- Sukulture Fest event page with a live countdown, event information, stall fee schedule, lineup placeholder, and photo-led archive.
- Responsive layouts and animated transitions between brand worlds.

## Run locally
Open `index.html` in a browser. The site is a static HTML/CSS/JavaScript experience and requires no build step.

## Content notes
Product photography and festival gallery imagery currently use replaceable visual placeholders. Replace these with the official Sukhavad campaign assets before public launch. Product prices, stock, artist lineup, ticket links, and complete contact details have not been invented; confirm these with the brand team before enabling transactions.
